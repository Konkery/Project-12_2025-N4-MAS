* Markdown: нумерованные CAPS-заголовки разделов; ОГЛАВЛЕНИЕ при объеме

## 5. СРЕДОВАЯ ОГЛЯДКА · ЛИМИТЫ ПРОВАЙДЕРА

* **Определение провайдера:** агент читает собственный блок идентичности модели
  (`Имя` / `Provider ID` / `Model ID`) на старте сессии и объявляет провайдер
  в первом ответе. Если идентичность не читается — спрашивает пользователя.
  Пользователь ориентирует агента словом при переключении провайдера.
* **Известные лимиты (тело запроса):**

  | Провайдер | Лимит | Источник |
  | :--- | :--- | :--- |
  | SELECTEL | 7 864 320 байт (7,5 МиБ) — ошибка `Request body too large` | подтверждён дважды, 11.10.2026 |
  | AITUNNEL | не измерен; заведомо выше 7,5 МиБ | наблюдение 11.10.2026 |

* **Гигиена контекста (обязательна при любом провайдере):**
  1. изображения читать **по одному**, крупные листы дробить на 2–4 части;
  2. разрешения не принижать сверх необходимого (режет — только по команде);
  3. массовый vision-разбор — **через субагентов**: агенту возвращается только
     текст, изображения в его истории не оседают;
  4. проанализированные изображения не перечитывать — выводы фиксировать
     текстом (roadmap / журнал);
  5. при приближении к лимиту — `/compact`; при отказе `Request body too large` —
     не повторять шаг, а сжать историю или перенести сессию по переходному промту;
  6. лимит SELECTEL — не повод для паники: при соблюдении п.1–4 провайдер
     работает штатно.
