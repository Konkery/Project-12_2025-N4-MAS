# 30__WATE-РЕНДЕР-РЕЗУЛЬТАТ · СТРУКТУРА И ПРАВИЛА
## Проект 12/2025-N4-МАС · каталог результатов генерации рендеров Horizon VM

> **Назначение.** Единая точка складывания **готовых** рендеров, полученных
> генерацией по моделям-базе Wate. Каталог — приёмочный: сюда попадают кадры,
> прошедшие проверку по чек-листу, а не любой вывод image-LLM.
> **🔒 Внутренний каталог.** Содержит производные от закрытой базы комплектующих;
> во внешние материалы переносится только обезличенный результат (рендер без
> признаков производителя-поставщика).

---

## 1. ПРИНЦИП РАЗБИВКИ

Два вложенных среза, оба интуитивны:

1. **`NN__МОДЕЛЬ`** — что рисуем (порядок = порядок работ, см. roadmap §11);
2. **`NN__ЭТАП-СОДЕРЖАНИЕ`** — на какой волне генерации кадр (порядок строгий:
   A → B → C, следующая волна только по **утверждённой** предыдущей).

Модель «закрывается» только после заполнения `08__утверждено` по всем нужным
этапам. Переход к следующей модели — только после Вашего «да» на текущей.

## 3. ИМЕНОВАНИЕ ФАЙЛОВ

Шаблон:

```
{модель}-{этап}{rev.NN}-v{NN}.{расш.}
```

Примеры:

* `L8050-A1-rev.01-v01.png` — первый вариант базы A1;
* `L8050-A1-rev.01-v02.png` — вторая итерация той же постановки (правка промта);
* `L8050-A2-rev.01-v01.png` — открытая дверь;
* `L8050-B2-rev.01-v01.png` — база + PTZ;
* `L8050-C2-rev.01-v01.jpg` — цех с людьми.

Правила:

* `rev.NN` — постановка задачи (что рисуем), `vNN` — вариант прогона. Новая
  постановка = новый `rev`; правки того же задания = рост `v`;
* в `08__утверждено` файл лежит под именем без суффикса варианта:
  `L8050-A1.png` (актуальный принятый кадр всегда узнаваем с первого взгляда);
* опорные изображения Wate (извлечённые из каталога/паспортов) сюда **не
  складываем** — они в `01__ИД\ид-аппаратов-wate\wate-models-img\`;
* русские буквы в именах файлов — допустимы только в именах каталогов этапов,
  имена результатов — латиница (устойчивее для image-LLM и скриптов).

* переходные промты генерационных сессий — в `03__Проект\temp\`;
* исходные фото/рендеры/логобук — в соседних `00__`–`70__` этого каталога.
